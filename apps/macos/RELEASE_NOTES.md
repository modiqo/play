# Play for Mac 0.1.2

Play for Mac guides users through sign-in, optional company setup, and Play installation across supported Mac harnesses.
It supports Apple Silicon and Intel Macs running macOS 13 or newer.

## Set up and manage Play

- Sign in with Google, GitHub, or an email code using the existing Rote account interfaces.
- Create an organization and invite colleagues, or continue with a personal account.
- Detect existing Play, Rote, and harness installations; review changes before installing or updating.
- See installed harness versions and copy starter commands or practical `/play explore` examples.
- Search published community, personal, and organization Plays through the shared search service.
- Use light, dark, or system appearance with native typography and compact controls.

The app returns to Home after successful installation or confirmed rollback.
Failure details remain available with a sanitized support report and a link to Modiqo Discord.
The installer handles missing optional skill folders and reuses the receipt already saved by the bootstrap transaction.

## Understand update and recovery behavior

The Update action updates Play and Rote in the installed harnesses.
The Mac application itself requires a new DMG download.
Play restores its prior configuration when installation verification fails; Rote updates remain forward-only.
The app does not index unpublished local Plays or automatically run copied prompts.
